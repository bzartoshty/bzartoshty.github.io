CHAPTER 2: ELEMENTARY PROGRAMMING - JAVA EXAMPLES

Extract the complete bundle before opening the presentation. Keep this folder
beside the PowerPoint. Slide links use Chapter02_Java_Examples/Filename.java.
In PowerPoint editing view use Ctrl+click; in Slide Show view click the link.

Compile: javac *.java
Run one example: java ComputeArea
All files are independent complete programs with main methods. Java 8+.
Use one chapter folder at a time to avoid duplicate class names across chapters.
In jGRASP, open any .java file and compile/run it.

PowerPoint includes printable Notes Pages with slide thumbnails, teaching
notes, discussion guidance, and quiz answers. The PDF contains slides only.

Valid numeric input is assumed. Examples that use decimal input select
Locale.US, so enter a period as the decimal separator. MonetaryUnits accepts
whole cents exactly; DollarsToCents is a rounding demonstration. GrossPay
assumes straight-time pay. LoanPayment assumes a positive annual rate,
1-100 whole years, and positive principal; it is not a loan quotation.
Read individual file headers for assumptions. Invalid code examples remain
commented so the entire folder compiles together.
