CHAPTER 3: SELECTIONS - JAVA EXAMPLES

Extract the entire bundle before opening the PowerPoint. Keep this folder
beside the presentation; links use Chapter03_Java_Examples/Filename.java.
Use Ctrl+click in PowerPoint editing view or click in a slide show.
Print PowerPoint using Notes Pages for slide thumbnails and teaching notes.
The separate PDF contains slides only.

Java 17+ recommended for the complete folder. Modern switch examples require
Java 14+. Other files use Java 8 features. Compile with: javac *.java
Run a file, for example: java GradeClassifier
In jGRASP, open a .java file and compile/run it. Each file is independent.
Keep each chapter in its own folder to avoid cross-chapter class-name clashes.

INPUT AND ASSUMPTIONS
Use a period for decimal input. Scanner reads whitespace-separated tokens.
NestedIf expects age and a true/false ticket flag, such as 20 true.
RandomDigit prints a new sample and digit each run. AdditionQuiz and
SubtractionQuiz ask random questions and read an integer answer.
LotteryDemo uses fixed draw 37 for reproducible branch testing.
Gross-pay rules are hypothetical marginal overtime bands, not payroll law.
Leap-year programs use the Gregorian arithmetic rule on positive years.
TriangleClassifier accepts integer sides 1-1000000 before checking validity.
Read each source header for its assumptions. Invalid token parsing is outside
these examples unless a program explicitly validates that input.

INTENTIONAL LOGIC ERRORS
GradeOrderPitfall, IndependentGradesPitfall, SemicolonPitfall,
BooleanAssignmentPitfall, and DebugGradeTrace demonstrate specified mistakes.
DanglingElse is deliberately brace-free. SwitchFallThrough deliberately
continues across colon labels. These programs compile and can be traced.
