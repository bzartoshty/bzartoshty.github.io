# COMP 110/L course materials

- `index.html` lists the course resources, chapter slides, and Java examples.
- `course.css` contains shared screen, mobile, and print styles.
- `Lectures/Chapter1` through `Lectures/Chapter11` hold the original lecture files and examples.
- `StudyGuide` contains exam review materials.
- `resources` contains the Java guide and the canonical jGRASP command-line tutorial.
- `syllabus` contains historical syllabus versions. Update the course page deliberately when selecting a current term.

Keep existing teaching-material filenames when possible so published links remain valid. The older `jgrasp_command_line_arguments/` URL redirects to the canonical tutorial. The extra lecture versions, syllabus copies, and screenshot URLs remain available for compatibility.

Java examples are separate classroom programs. Compile examples in their chapter context, rather than compiling every chapter together: classes such as `Circle`, `Rectangle`, and `Calculator` occur in more than one chapter.
